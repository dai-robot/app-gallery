国会議事録・NDL書誌トレンド検索

関連語グループを入力し、国立国会図書館の書誌データと国会議事録の年次件数、初出年、文脈サンプルを確認します。初期範囲は2000年以降、年範囲は後で1948年まで広げられる構造です。

対象2 API
初期範囲2000+
実行HTML

検索条件

データ単位: NDL書誌は「本のタイトルに語が含まれる書誌レコード件数」、国会議事録は「本文に語が含まれる発言単位の検索ヒット件数」です。実APIモードは年数×語数ぶん逐次取得するため時間がかかります。
条件を入力して集計すると、初出年と年次推移が表示されます。

年次推移

比較モードでは同じ検索グループを両データ源へ適用します。

文脈サンプル

文脈は集計後に、指定した年・語・データ源だけを最大20件取得します。重い本文取得を常時走らせないための設計です。

利用条件メモ

NDLサーチはSRU API、国会会議録は検索用APIを利用します。静的HTMLではブラウザのCORS制約で実API取得が止まる場合があります。その場合はサンプル値でUIを確認し、実運用では軽量プロキシまたはサーバーAPIを挟む構成にしてください。
